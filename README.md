# JobSphere

JobSphere is a full-stack recruitment platform that connects candidates and recruiters through a secure REST API.

## Features

### Candidate
- Register and login
- Manage candidate profile
- Search and filter jobs
- Apply for jobs
- Track application status

### Recruiter
- Register and login
- Manage recruiter profile
- Create jobs
- Update jobs
- Delete jobs
- View applicants
- Update application status

### Admin
- View users
- View jobs
- View applications
- Delete users
- Delete jobs
- Delete applications

## Technology Stack

### Backend
- Java 17
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- Hibernate
- MySQL
- REST API

### Frontend

- JavaScript
